# 第五章 习题

## 习题

1. DMA 设备与处理器是否会争抢内存带宽资源? 存储器层次设计的优劣对此问题有何影响?

    DMA 设备和处理器会争抢内存带宽资源. 好的存储器层次设计能使得 CPU 的内存访问尽可能在 Cache 中完成, 从而将内存带宽交给 DMA 使用, 降低竞争. 但 DMA 也可能带来 Cache Coherence 的问题, 需要更复杂的存储器层次设计.

2. 串行总线比并行总线有何优势? 试简述造成它们接口速率不同的原因.

    串行总线所需线路数量少, 体积小且成本低; 不存在各条数据线之间的干扰, 抗干扰能力强; 不需要考虑各数据线之间的同步问题, 传输速度快距离远.

    并行总线接口速率主要受限于时钟频率, 过高的频率会导致严重的时钟偏斜. 串行总线由于不需要考虑各数据线之间信号的同步, 可以拥有极高的频率, 因此接口速率远超并行总线.

3. 根据 I2C 的帧格式, 解释其为半双工的原因.

    I2C 只有两根线, 一根 SLC 时钟线和一根 SDA 数据线. 根据 I2C 的帧格式, 传输数据时先由主设备发送 7 位地址和 1 位 R/W, 再根据读或写进行单向数据传输. 数据线可以双向传输数据, 但同一特定时间段内只能有单个方向的数据传输, 因此为半双工.

4. 简述磁盘控制电路如何通过决定请求的最优执行次序来减少磁盘访问用时?

    磁盘访问时间包括寻道时间, 旋转时间和数据传输时间. 其中, 寻道时间和旋转时间是访问时间的主要来源, 而两者均可以通过磁盘控制电路进行优化. 通过调整请求的执行次序, 可以大幅降低磁头来回移动, 从而减少磁盘访问时间.

5. 若某一块磁盘的 MTTF 为 n 小时, 试计算由 4 块这种磁盘组成的 RAID0 的 MTTF. 若每一块磁盘的可用容量为 50G, 而系统只需要 80G 的存储空间, 试设想一种方案, 使得 4 块磁盘组成的 RAID 达到尽可能大的 MTTF.

    RAID0 中无冗余, 4 块磁盘的失效率 $\lambda = 4 \times \frac{1}{n} = \frac{4}{n}$, 因此 $\text{MTTF} = \frac{1}{\lambda} = \frac{n}{4}$.

    采用 RAID6, 可容忍 2 块磁盘同时故障, 并保证足够的存储空间.

6. 试分析 RAID4 中的写入优化对于读取速度的影响.

    RAID4 中, 通过利用异或运算的性质, 可以只需要读取目标磁盘和校验磁盘并计算校验位的改变情况, 从而避免多次读取其余磁盘, 减少总读取次数. 因此在每次写入的同时其他磁盘仍然能够并行读取, 从而优化读取速度, 但这仍将带来较大的目标磁盘和校验磁盘开销.

7. 根据 I/O 请求花费在队列系统中的平均响应时间公式, 分析 7.5 节中, 随着磁盘 I/O 请求减少, 磁盘队列系统的性能提升幅度缩小的原因.

    平均响应时间 $W = \frac{1}{\mu - \lambda}$.

    随着磁盘 I/O 请求减少, 生长率 $\mu$ 很低, 消亡率 $\lambda$ 带来的提升表现出明显的边际递减效应.
