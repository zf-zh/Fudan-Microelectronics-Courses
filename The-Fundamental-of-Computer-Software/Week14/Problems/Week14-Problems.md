## 4-13. 已知一棵三次树转换为二叉树后的括号表示为

A(B(E(,F(,G)),C(,D(H(J(,K(,L)),I),))),)

### 4-13-1. 写出该二叉树的后序遍历.

```
       A
      /
     B
   /   \
  E     C
   \     \
    F     D
     \   /
      G H
       / \
      J   I
       \
        K
         \
          L
```

后序遍历为 G, F, E, L, K, J, I, H, D, C, B, A.

### 4-13-2. 画出转换前的三次树.

```
           A
         / | \
       /   |   \
     B     C     D
   / | \        / \
  E  F  G      H   I
             / | \
            J  K  L
```

### 4-13-3. 写出该三次树的后序遍历.

后序遍历为 E, F, G, B, C, J, K, L, H, I, D, A.
